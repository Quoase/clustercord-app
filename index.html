GUIA DO CLUSTERCORD

Documentação
para começar

Um guia introdutório para conhecer o projeto, instalar o aplicativo e entender como acessar a versão web.

1. O que é o Clustercord?

O Clustercord é um projeto de comunicação que oferece uma experiência de chat pela web e, agora, também uma versão instalável para Windows. Esta página funciona como ponto de entrada: daqui você pode baixar o aplicativo, abrir o WebChat e consultar orientações básicas. A versão web continua disponível, então você não precisa instalar o programa para visitar o serviço.

O instalador empacota o acesso ao Clustercord em um aplicativo de desktop. Ele não substitui o site: as duas formas de acesso coexistem e você pode escolher a que melhor combina com seu uso.

2. Como baixar e instalar no Windows

Use um dos botões “Baixar” desta página para obter o arquivo de instalação. Depois que o download terminar, abra o arquivo .exe e siga as instruções apresentadas pelo instalador. Se o Windows perguntar se você permite que o aplicativo faça alterações no dispositivo, confira se o arquivo é o instalador que você acabou de baixar e se veio do endereço oficial do projeto antes de prosseguir.

Após a instalação, procure o Clustercord no menu Iniciar ou no atalho que o instalador tiver criado. Se houver uma versão anterior instalada e você encontrar problemas, feche o aplicativo antes de executar novamente o instalador. As etapas e telas podem variar conforme a versão do Windows.

3. Aviso do Windows SmartScreen

Neste momento, o instalador não possui uma assinatura digital de editor. O SmartScreen pode, portanto, mostrar uma mensagem como “O Windows protegeu o computador” ou informar que o aplicativo é desconhecido. Esse aviso pode ocorrer com programas novos ou pouco conhecidos; ele não confirma automaticamente que o arquivo é perigoso, mas também não comprova que seja seguro.

Aviso sobre a instalação no Android (Play Protect)

Como o APK do Clustercord ainda não possui uma assinatura de desenvolvedor verificada nem é distribuído pela Google Play, o Google Play Protect pode exibir um alerta ou impedir a instalação. Isso pode acontecer com aplicativos instalados por fora da loja oficial.

Esse aviso, por si só, não significa que o APK seja malicioso — mas também não garante que um arquivo seja seguro. Continue somente se tiver baixado o APK da página oficial do Clustercord e confiar na origem do arquivo. Se o Play Protect indicar um risco específico, recomendamos não ignorar o alerta até que a origem e o arquivo sejam verificados.

Se você obteve o instalador diretamente do repositório oficial do Clustercord e verificou que o arquivo é o esperado, clique em “Mais informações”. Se o Windows oferecer a opção, você poderá escolher “Executar assim mesmo”. Se não reconhecer a origem do arquivo, se o nome não corresponder ao esperado ou se algo parecer suspeito, cancele a execução. Pretendemos providenciar uma assinatura digital futuramente, para que o Windows possa identificar melhor o editor.

4. Usar o Clustercord pelo navegador

O WebChat permanece disponível em quoase.github.io/clustercord/. Basta abrir o endereço em um navegador compatível. Essa opção é útil se você estiver em outro computador, não puder instalar programas ou simplesmente preferir usar o serviço no navegador.

O site de download e o WebChat são páginas diferentes: esta central oferece o instalador e informações; o link do WebChat abre a aplicação web. Salve o endereço do WebChat nos favoritos caso queira acessá-lo rapidamente.

5. Atualizações, problemas e boas práticas

Quando uma versão mais recente do instalador for publicada, volte a esta página e confira as informações da versão antes de atualizar. Feche o aplicativo antes de instalar uma atualização. Não baixe instaladores enviados por desconhecidos nem execute cópias com nomes diferentes sem confirmar sua procedência.

Se o aplicativo não abrir, tente verificar se o download terminou por completo, se o Windows exibiu algum alerta e se há uma mensagem de erro específica. Anote o texto do erro e a versão do Windows: esses detalhes ajudam a investigar o problema. Evite compartilhar informações pessoais, senhas ou dados privados em capturas de tela de suporte.

6. Sobre esta documentação

Este é um guia inicial, não uma especificação técnica completa. Ele descreve os caminhos de acesso e cuidados gerais com o instalador, mas não promete recursos internos que não estejam documentados aqui. Conforme o projeto evoluir, esta seção poderá receber informações sobre versões, requisitos, perguntas frequentes, solução de problemas e novidades.

Para acessar o serviço agora, use o botão de download no topo para instalar o aplicativo ou abra o WebChat pelo link da navegação.
